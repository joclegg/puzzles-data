# puzzles-data

The puzzle banks and word lists shared by [puzzles-android](https://github.com/joclegg/puzzles-android) and [puzzles-web](https://github.com/joclegg/puzzles-web). Both apps include this repository as a git submodule at `puzzles-data/`.

One puzzle per line. Files are plain text.

| Folder | Files | Line format |
| --- | --- | --- |
| `sudoku/` | `<mode>_<level>.txt` | `givens\|solution\|cages`: 81 (or 36) digits each, `0` for an empty given. Killer cages are `sum:cell,cell,...` joined by `;`; empty for classic. |
| `kakuro/` | `<size>.txt` | `size;solution;givens`: the solution row by row, `0` for a black cell, then the given cells as indexes joined by `,`. |
| `slideout/` | `<level>.txt` | `par;blocks`: par is the fewest moves; each block is `row col length H\|V`, the red block first. Levels: beginner 4–9 moves, easy 10–16, medium 17–24, hard 25–32, expert 33+. |
| `solitaire/` | `<draw>_<order>.txt` (`drawOne_down`, `drawThree_up`, ...) | One deal seed per line, as a signed 64-bit number. Each seed's deal is proven winnable for that draw mode and build order. Generated by puzzles-web's `scripts/solitaireBank.mjs`. Daily deals use only the first 1,000 lines, so only append: more lines add variety to random deals without changing any daily deal. |
| `words/` | `answers.txt`, `guesses.txt` | Five Letters: one lowercase word per line. |
| `wordwheel/` | `five.txt`, `six.txt`, `seven.txt`, `valid.txt` | `letters;placements`: the wheel's letters, then each crossword word as `WORD@row,col,A\|D` (across or down) joined by `\|`, the word using every letter first. `valid.txt` holds the accepted words, one uppercase word per line. See `wordwheel/NOTICE.md` for the word lists' licence. |

`scripts/check_duplicates.py` fails if a bank holds the same puzzle twice (Slide Out blocks after the red one may be in any order); CI runs it on every push.

Every merge to `main` publishes the banks to https://joclegg.github.io/puzzles-data/ (`.github/workflows/publish.yml`), with `manifest.json` listing each file's SHA-256 and line count. The apps download changed banks from there and keep them on the device, so new puzzles reach players without an app release.

The generators live in puzzles-android (`./gradlew :<game>:engine:generateBank`) and write here.
